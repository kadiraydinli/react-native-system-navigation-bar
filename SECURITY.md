# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 3.x     | Yes       |
| < 3.0   | No        |

The v2 line receives no further updates, including security fixes.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, use one of the following channels:

- [Report a vulnerability privately](https://github.com/kadiraydinli/react-native-system-navigation-bar/security/advisories/new) through GitHub's private vulnerability reporting.
- Email [hello@kadiraydinli.com](mailto:hello@kadiraydinli.com) with the details.

Include a description of the issue, steps to reproduce, and the affected version(s). Please allow a fix to be released before disclosing the issue publicly; fixed vulnerabilities are documented in the release notes.

## Scope

This library runs entirely on-device and makes no network requests. Reports about the example app, development tooling, or dependencies with no exploitable path through the library's public API are appreciated but will generally be handled as regular issues.
